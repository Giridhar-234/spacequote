# SpaceQuote

Online quotation app for interior designers in India.

- `site/index.html`: the whole app. Netlify publishes only the `site` folder.
- `setup/firestore-rules-batch3.txt`: Firestore security rules (paste in Firebase console → Firestore Database → Rules).
- `setup/realtime-database-rules.json`: Realtime Database rules (paste in Firebase console → Realtime Database → Rules).
- `setup/SpaceQuote-alerts.gs`: Google Apps Script for owner email alerts and the Google Sheet export.

Keep this repository private.
